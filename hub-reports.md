A dashboard is only useful if the reader knows what a number means, which period it covers and what a good result looks like. Each report below has its own page with the interactive report at the top and a reading guide underneath. The report loads only when you ask for it, which keeps the page fast and avoids loading Microsoft's scripts for readers who only want the guide.

The reports are hosted by Microsoft Power BI and open inside a frame. If your network blocks the embedded view, every page has an "Open in a new tab" link. For everyday use the [workspace](/portal/) opens the reports straight away and lets you switch between them without leaving the page.

New to reading performance dashboards? The [how it works](/guides/how-it-works/) guide covers the basics of filters, slicers and cross-highlighting, and the [glossary](/glossary/) defines the measures you will meet.
