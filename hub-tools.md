Each tool has its own page with the tool at the top and, underneath, an explanation of how it works, a worked example you can reproduce, the mistakes people commonly make, and answers to common questions. If you would rather work in one window all shift, the [workspace](/portal/) holds every tool and the Power BI reports side by side.

**Which should I open first?** For timing and notes, start with the Call Scratchpad and the AHT Timer. For a customer asking about a booking, start with the Cancellation Deadline Checker and the Booking Price and Change Calculator. For calls with hotels, agencies and partners, the Lodging Case Note Builder, the Commission and Net Rate Calculator and the Partner SLA Due-Time Calculator are the three most used.

Tools that work with dates ask for the time zone, because a cancellation deadline or a response time is only correct in the zone that the policy or the agreement names. Tools that work with money use whole cents internally, so totals never drift by a rounding error.
